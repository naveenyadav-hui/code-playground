# code-playground

A grab-bag of small scripts and snippets to fork and build on later. Nothing here is precious: break it, extend it, rewrite it.

## What's inside

| Path | What it does |
| --- | --- |
| `python/fizzbuzz.py` | Classic FizzBuzz with a configurable range |
| `python/word_counter.py` | Prints the most common words in a text file (stop words ignored by default; `--all` keeps them) |
| `python/guess_the_number.py` | Terminal number-guessing game |
| `js/todo.js` | Tiny in-memory todo list class |
| `snippets/ideas.md` | Checklist of things to build next |

## Run something

```bash
python python/fizzbuzz.py 20
python python/word_counter.py README.md
python python/word_counter.py README.md --all
python python/guess_the_number.py
node js/todo.js
```

## Fork it

1. Click **Fork** at the top of this page.
2. Pick an idea from `snippets/ideas.md`.
3. Build it, commit, and open a pull request.
